# Assets Folder

## Purpose
This folder contains all static assets for your portfolio (images, audio, etc.)

## Structure

### 📁 images/
Place all your images here:
- `profile.jpg` - Your profile photo for About section (800x800px recommended)
- `skill-*.jpg` - Optional skill showcase images
- Current placeholders are SVG files (can be replaced)

### 📁 audio/
Place your music files here:
- `interstellar-theme.mp3` - Background music (or your preferred track)

## Quick Start

1. **Add your profile photo:**
   - Copy your photo here: `images/profile.jpg`
   - Make sure it's 800x800px and < 200KB

2. **Update the component:**
   - Open: `src/components/sections/About.jsx`
   - Change: `src="/assets/images/profile.jpg"`

3. **Test:**
   ```bash
   npm run dev
   ```
