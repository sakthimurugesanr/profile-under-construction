# 🚀 Quick Start Guide

## Get Your Portfolio Running in 3 Steps!

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```

### Step 3: Open in Browser
Navigate to: **http://localhost:5173**

---

## 🎯 What to Test First

### 1. Interactive Grid (NEW!)
- Scroll down to the "Interactive Experience" section
- **Hover Mode**: Move mouse over grid cells
- **Ripple Mode**: Click the toggle, then click grid to create waves
- **Mobile**: Touch and drag across grid

### 2. Magnetic Effects
- **Header Logo**: Hover near it (cursor follows)
- **"Get in touch" button**: Hover to feel magnetic pull
- **Hero buttons**: Magnetic attraction effect

### 3. 3D Tilt Cards
- **Projects section**: Hover over project cards
- **Stack section**: Hover over stack cards
- Watch them tilt in 3D following your mouse!

### 4. Scroll Animations
- Watch the **progress bar at top** as you scroll
- **Experience section**: Entries animate as you scroll
- **All sections**: Smooth reveal animations

### 5. Hero Section
- **Name animation**: 3D rotation entrance
- **Stats cards**: Bouncy entrance
- **Background grid**: Parallax effect

## 📱 Mobile Testing

1. Open browser DevTools (F12)
2. Click "Toggle Device Toolbar" (Ctrl+Shift+M)
3. Select a mobile device
4. Test touch interactions on Interactive Grid

## 🐛 Troubleshooting

### Port Already in Use?
```bash
npm run dev -- --port 3000
```

### Animations Not Working?
- Check browser console for errors
- Make sure GSAP is installed: `npm list gsap`
- Hard refresh: Ctrl+Shift+R

### Grid Not Showing?
- Check if JavaScript is enabled
- Try a different browser
- Check console for errors
